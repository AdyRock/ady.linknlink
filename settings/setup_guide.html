LinknLink App Setup Guide (Homey + LinknLink)

This guide covers complete setup for LinknLink devices with Homey using MQTT, including the LinknLink mobile app side.

1. Prerequisites

  1. Homey Pro running this LinknLink app.
  2. LinknLink mobile app installed and device already added there.
  3. Your LinknLink device online on your LAN.
  4. An MQTT broker ready (either Homey built-in broker from this app, or external broker).

2. LinknLink Mobile App Steps (Required)

  1. Open LinknLink mobile app and open the target device.
  2. Tap the ... menu (top-right corner).
  3. Open MQTT Connection.
  4. Enter broker details that match Homey app settings exactly.
  5. Tap Save.
  6. Reopen MQTT Connection and confirm status shows Connected.
Important: If the LinknLink device is not connected to MQTT, Homey cannot discover entities from it.

3. Homey App Settings

Open the app settings page in Homey and configure broker credentials.

Setting Meaning Typical values
Use app's built-in MQTT broker Runs local broker inside Homey app. Enabled for easiest setup.
Broker URL / IP Host of the MQTT broker. localhost (built-in) or LAN IP (external).
Broker Port MQTT TCP port used by Homey app client and LinknLink devices. Built-in default in this app is 10883.
Broker WebSocket Port MQTT WebSocket listener for WS clients. Built-in default in this app is 18888.
Username / Password Broker auth details. Must match what you set in LinknLink app device MQTT settings.

4. Built-in Broker vs External Broker

Important distinction: Use app's built-in MQTT broker only applies if you want to use the broker embedded inside this LinknLink app itself. If you are using any other broker, including a separate broker running on Homey, that counts as the External Broker setup and this option should be disabled.

Built-in Broker (recommended for most users)

  1. Enable Use app's built-in MQTT broker only when you want this app to host the MQTT broker.
  2. Keep defaults unless needed: localhost, 10883, 18888.
  3. Use same credentials in LinknLink app MQTT Connection.

External Broker (advanced)

  1. Disable Use app's built-in MQTT broker.
  2. Set external broker IP/host and port.
  3. If the broker is running elsewhere on Homey rather than inside this app, still use this external broker setup.
  4. Set matching credentials in both Homey settings and LinknLink app.
  5. Ensure Homey and LinknLink devices can reach that broker on the network.

5. Save and Confirm

  1. Click Save Settings in Homey app settings.
  2. You should see success feedback and a reminder message.
  3. If broker warning appears, check that selected port is not already in use.

6. Pair Device in Homey

  1. Go to Add Device in Homey.
  2. Select this LinknLink app.
  3. Choose and pair discovered device(s).

Supported drivers currently include eMotion Pro, eMotion Ultra/Ultra2, TV remote, AC remote, and a new trait-based eMotion path for original eMotion models.

7. Verify Data and Flows

  1. Presence updates should toggle when motion/presence changes.
  2. Light, temperature, humidity, and signal values should update when available.
  3. Create a basic flow on presence change and test.

8. Troubleshooting

Device not discovered in Homey

  • Confirm LinknLink app device MQTT status is Connected.
  • Confirm broker host/port/user/pass match exactly in both apps.
  • Enable logs in Homey settings and retry pairing.

Broker warning in Homey settings

  • TCP port in use: change broker port or stop conflicting service.
  • WebSocket port in use: change WS port or stop conflicting service.
  • If you are not using the broker built into this app, disable Use app's built-in MQTT broker and follow the External Broker setup instead.

Device pairs but some values missing

  • Check app log for mapping diagnostics and share those lines with the maintainer.
  • Relevant log patterns include:
  • eMotionDriver matched model ... using traits ...
  • No capability mapping for device ... entity ... component ...
  • processMQTTMessage error ...

9. Recommended Test Report for Users

  • Homey app version and Homey firmware version.
  • Exact LinknLink model name shown in LinknLink app.
  • Broker mode (built-in or external) and ports used.
  • What works vs what is missing.
  • Relevant app log excerpt around pairing and first data updates.

Tip: Keep this guide open beside the settings page while doing setup, and work section by section. Most integration issues come from a broker mismatch or MQTT not connected on the LinknLink side.
